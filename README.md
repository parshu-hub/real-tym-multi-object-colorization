# Real-Time Multi-Object Colorization with Semantic Segmentation

## Problem Statement
This project performs real-time multi-object colorization on webcam or uploaded video using semantic segmentation.

## Features
- Webcam input
- Video upload
- Semantic segmentation
- Colorized output
- GUI interface
- FPS display

## Technologies Used
- Python
- OpenCV
- PyTorch
- Torchvision
- NumPy
- Tkinter
- Matplotlib

## Files
- app.py
- gui_app.py
- segmentation_utils.py
- requirements.txt

## How to Run
### Run basic webcam version
```bash
python app.py
